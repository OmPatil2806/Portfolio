7 projects

01 Public benchmark data

RF Failure Root Cause Analysis

Predicts the failure, explains why, and ranks the repair.

Six-layer ML pipeline over three public benchmark datasets mapped to one RF parameter schema. XGBoost and a PyTorch 1D-CNN predict failure, SHAP and GradCAM explain it, and a 42-node knowledge graph turns the explanation into ranked P1/P2/P3 repair actions.

  • F1 0.959 tuned XGBoost, CMAPSS
  • 160,359 sensor rows
  • 5-page Streamlit dashboard

02 Real logs + injected faults

Automotive Diagnostic Log Analyzer

Flags a developing fault in OBD-II logs before the fault code appears.

Isolation Forest plus a range score per subsystem, with root-cause attribution, vehicle health scoring and PDF/HTML/JSON reports. Normal behaviour is learned from real Vehicle Energy Dataset logs; six faults were injected to evaluate on unseen trips.

  • 90% faulty trips detected
  • 7.5% false alarms
  • F1 0.87

05 Synthetic data

FinCast

Forecasts next month's income, spending and balance, with a range instead of a single guess.

LightGBM forecasts with 10-90% quantile intervals, validated by rolling-origin backtesting, plus auto-categorisation, anomaly alerts, a what-if simulator and savings goals.

  • 6.9% lower MAE than best baseline
  • 85% of actuals inside the range
  • 289 tests, 92% coverage

Smart Grid Electric Load Forecasting

Forecasts hourly electricity demand with LSTM networks.

A three-layer LSTM (128, 64 and 32 units with dropout) compared against a feedforward baseline on Kaggle hourly electricity-consumption data, with exploratory analysis of daily, weekly and temperature patterns and an actual-vs-predicted forecast view.
