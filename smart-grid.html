Smart Grid Electric Load Forecasting

Forecasts hourly electricity demand with LSTM networks.

  • LSTM vs feedforward baseline
  • 128-64-32 LSTM units
  • MAE and MSE evaluation
View on GitHub

Problem

Accurate load forecasts support grid reliability, energy planning and demand planning. Getting the next hours right is what lets an operator schedule generation instead of reacting to it.

Data

Source
Kaggle “Hourly Load Consumption Data” — an hourly time series.
Input window
24-step sequences.

EDA views: 7-day rolling load trend, average load by hour, weekday versus weekend distribution, and load against temperature.

Approach

  • Preprocessing, feature scaling and sequence windows with a 24-step input.
  • A feedforward neural network as the baseline to beat.
  • A stacked LSTM — 128, 64 and 32 units, dropout after each layer, single dense output.
  • Evaluated with MAE and MSE, followed by an actual versus predicted chart.

Results

Status

Numeric results are not published yet. There is no score to report here, and none is implied by the chart-free layout of this page.

Planned next: hyperparameter tuning, weather and calendar features, real-time forecasting, and a Streamlit or Flask deployment.

Limitations
& honest notes

  • No published metrics yet — the model is evaluated with MAE and MSE, but the numbers are not final.
  • No weather or calendar features in the current version.
  • Not deployed; it runs in a Jupyter notebook.
