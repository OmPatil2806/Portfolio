RF Failure Root Cause Analysis

Predicts the failure, explains why, and ranks the repair.

  • F1 0.959 tuned XGBoost, CMAPSS
  • 160,359 sensor rows
  • 5-page Streamlit dashboard
View on GitHub

Problem

Most predictive-maintenance tools only flag that something will fail. That leaves the hardest part to the technician: deciding what actually broke and what to do first. This system also names the likely root cause and returns a prioritised repair plan.

Data

NASA CMAPSS
709 engines, 160,359 rows, 14 sensors. Failure defined as RUL ≤ 30 cycles.
UCI SECOM
1,567 samples, 562 features, 6.6% failure rate, balanced with SMOTE.
Kaggle AI4I 2020
10,000 samples across 5 failure types.
Unified schema
All three mapped to 8 RF parameters — 32,198 rows in the common schema.

Approach

  • Ingestion and feature engineering across the three sources into one parameter schema.
  • 48 EDA plots to establish distributions and sensor behaviour before modelling.
  • XGBoost and a PyTorch 1D-CNN over 30-cycle windows, combined in a soft-vote ensemble weighted 55% / 45%.
  • MLflow for experiment tracking and Optuna for hyperparameter search (20 trials).
  • SHAP for tabular attribution and GradCAM for the CNN.
  • A NetworkX knowledge graph — 16 symptoms, 12 causes, 14 repairs, 53 edges — scoring each repair as SHAP weight × cause weight × repair weight.

Results

Weighted F1 — full 0 to 1 scale

XGBoost — baseline0.9521
XGBoost — tuned0.9589
AI4I 6-class0.9477
Ensemble0.9466

All four models land within roughly one point of each other, so the bars are deliberately drawn on a full 0–1 scale rather than a zoomed one. The 1D-CNN reached 0.8666 accuracy as a separate architecture.

Example output

A degraded engine is diagnosed as sensor degradation with bearing wear as the primary cause. The plan comes back ranked: P1 inspect or replace the bearing (4 h), P2 replace seals (6 h), P3 re-torque the connector (15 min).

Dashboard pages: EDA Explorer, RCA Analyzer, Model Compare, Knowledge Graph, Live Simulator.

Limitations
& honest notes

  • The soft-vote ensemble scored below the tuned XGBoost model — combining the two did not help here.
  • The headline F1 of 0.9589 is on CMAPSS only, not across all three datasets.
